项目

LinkRadar

LinkRadar 是一个面向无权无向网络的单机多核图分析项目，基于 Brandes 算法计算全源介数中心性。项目结合 CSR、Numba、树商图和线程并行，并支持检查点续算，提供交互展示。

类型： Course Project

成员： 刘宇翔

GitHub： https://github.com/lyx0902/LinkRadar

项目详情

大规模网络关键节点识别与并行计算

技术栈：Python、NumPy、Numba、NetworkX、Multiprocessing、HTML/CSS/JavaScript

精确图算法与数据处理

面向无权无向网络实现 Brandes 全源介数中心性算法，通过 BFS 统计最短距离与等长路径数量，逆序累积节点依赖；构建边列表清洗、节点编号映射和图指纹校验流程，支持真实网络数据导入与结果复现。

图结构压缩与结果恢复

设计外围树商图，将连接同一核心锚点的原始源点按数量权重分组，在核心图上执行带权计算，并结合树结构恢复原图节点贡献；在 YouTube 数据上，将需遍历的源组从 1,134,890 个原始源点对应的逐源遍历减少至 470,164 个核心源组。

编译内核与多核并行

使用 CSR 数组紧凑存储图结构，通过 Numba 将最短路径搜索与依赖累积编译为释放 GIL 的本机代码；按源组动态分批调度，线程共享只读核心图并维护私有工作区，计算后归并局部贡献。

最短路径边记录优化

在正向 BFS 中记录满足层次条件的最短路径后继边，反向累积时直接访问有效边，减少重复邻接扫描；在 YouTube 核心图的 64 个源组、4 线程、三轮配对实验中，执行与归并阶段的加速比中位数为 1.436×。

长任务检查点与断点续算

实现双累计快照机制，按分块交替写入核心贡献，结合哈希校验和清单原子提交恢复已完成进度；完成 YouTube 全源任务，8 线程下两次会话监督墙钟合计约 2 小时 30 分，不含会话间停顿。

正确性验证与结果展示

对小图及两张真实网络的全节点结果进行 NetworkX 对照；通过源覆盖、文件哈希和外围树公式核验大图结果，并构建固定排名节点移除实验与交互式看板，展示介数、度数和随机策略下的连通性变化。

AchievementAnalysis

整体项目： 整合Steam多源数据，分析游戏趋势、聚类、口碑与玩家投入，实现可解释推荐及交互展示。

个人任务： 完成成就自动分类与主线推进分析，结合玩法、时长和口碑解释玩家投入，数据可视化。

类型： Course Project

成员： 王文海，刘宇翔，杨金辉，耶美田，朱政宇

GitHub： https://github.com/WwhdsOne/achievement-analytics

项目详情

基于 Steam 成就的主线推进与玩家投入分析

成就语义标注流水线

基于 DeepSeek 构建整款游戏成就多标签分类流程，将游戏名称、类型及成就原文组织为结构化输入，覆盖主线、支线、收集、挑战等 8 类标签；实现成就 ID 完整性、标签互斥规则及原文证据引用校验，按标签置信度筛选入库，累计覆盖 803 款游戏、48,390 项成就，写入 51,854 条分类标签。

可靠调用与可恢复执行

设计版本化提示词、请求指纹缓存与缓存响应重校验机制，结合请求预算、累计超时、退避重试及进度记录控制批量调用；采用 SQLite 逐游戏事务提交，隔离单款失败，保留低置信度候选与异常响应，支持依据已提交结果和有效缓存继续处理，避免中断后重复调用与整体回滚。

主线指标构建与过程分析

复用小组既有主线标签及剧情节点顺序，建立首、中、末节点覆盖率与前段、后段、全程推进比，处理缺失分母、多结局代表节点及覆盖率逆跳等口径问题；形成 198 款游戏指标底表、183 款完整三节点样本，展开 1,543 个相邻节点区间，定位终点表现相近但阶段落差不同的游戏案例。

多源关联实验与不确定性评估

按 AppID 联结 RAWG 游玩时长、HLTB 参考耗时与 Steam、Metacritic 评分，采用共同样本对照、并列平均秩 Spearman 及 2,000 次游戏级成对 Bootstrap 开展统计分析；在 69 款时长共同样本中，测得绝对时长、相对主线耗时投入比与全程推进的 ρ 分别为 0.289、0.652，报告置信区间并区分统计关联与因果解释。

可解释同类参照基线

基于完整玩法多标签构建 Jaccard 相似度参照，结合相同结局口径、排除自身及最小参照数量约束，计算阶段推进相对同类的中位数差、四分位范围和百分位位置；为 181 款游戏提供有效主参照，并通过相似度阈值、口碑及内容长度条件对照，检查相对表现对参照选择的敏感性。

分析交付与交互可视化

将公共指标及五个分析专题整合为 21 组 PNG/SVG 图表、明细与汇总 CSV 及交互网页，支持按 AppID、中英文名称选择 1—5 款游戏，联动阶段对比、完整曲线与条件切换；采用离线预计算、来源指纹校验和 HTML 数据内嵌，保证选择仅影响高亮与明细，成品浏览无需数据库、模型接口或分析后端。

ApexLogic

多智能体深度研究系统，融合多源检索与迭代评审，支持断点续研、跨任务记忆复用及后台并发执行。

类型： Research Project

成员： 刘宇翔

GitHub： https://github.com/lyx0902/ApexLogic

项目详情

基于 LangGraph 的开放域深度研究与问答的多 Agent 系统

技术栈：Python, LangGraph, Multi-Agentic Workflow, Thompson Sampling, AQD, IRCoT, PostgreSQL, Redis, Streamlit

多智能体编排与反思图闭环

基于 LangGraph 状态图构建 Researcher → Writer → Reviewer 工作流，跨轮持久化检索策略参数、推理链与修订记录；设计事实准确性、逻辑完整性、信息覆盖和可执行性四维评审，将证据缺口与结构化修订指令接入条件路由，实现“检索—写作—评审—补搜／修订”自动化闭环。

多策略协同检索优化

集成 DuckDuckGo、Tavily、arXiv 三路异构信源，利用 BGE-M3 向量召回与重排完成 Top-20 → Top-10 两阶段筛选，以重排得分反馈 Thompson Sampling，动态分配搜索源结果配额；结合 AQD 子问题分解与 IRCoT 多跳补搜，通过普通检索／推理补搜双通道上下文保留关键证据及引用链路。

跨任务记忆与检索复用

构建基于 PostgreSQL / pgvector 的来源证据记忆，持久化报告引用的原文摘录、来源、有效期和向量；逐子问题检查证据覆盖、版本与时效，仅对满足条件的问题省去预计划搜索，保留必要证据进入写作上下文；接入 Redis 搜索与向量缓存，实现 TTL 失效、并发请求合并及故障旁路处理。

多并发调度与可恢复执行

设计“任务级多进程 Worker + 检索级有界线程池”两级并发机制，基于 PostgreSQL 事务 outbox 与 Redis Stream 消费者组解耦页面提交和后台执行；结合任务互斥锁、租约心跳、Worker 并发数管理，协调任务领取和外部工具调用，通过数据库扫描补偿通知丢失并接管失联任务；基于 LangGraph 同步 checkpoint 与配置快照校验实现节点级断点恢复，保留已提交进度，避免中断后从头重跑研究流程。

意图路由与报告交互

开发可选 Jev 分类与结构化 LLM 兜底的操作识别链路，设置置信度门槛、目标任务校验和澄清分支，将模型判断与实际执行分离；支持报告追问、增量更新、改写和核验，独立保存问答、检索来源及报告版本，通过 Streamlit 展示节点进度、检索入选、评审路由和意图审计。

量化评测与迭代验证

建立 HotpotQA 分层评测集，对比 DeepSeek-V3.2、Qwen3-Max 等模型基线，Medium 档准确率达到 72.0%，对比 DeepSeek-V3.2 的 61.3%；Hard 档正确率提升 20%+；针对降级误放行、解析异常等 Bad Case 完善处理逻辑，补充大量 pytest 评审单元测试，并配套对应说明文档。
